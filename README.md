## ✨ What is JustSwap?

**JustSwap** is a peer-to-peer item exchange platform designed around a simple idea:

> **You have something someone else wants. They have something you want. Why buy when you can swap?**

Users can explore available items, view item details, discover other users, and propose exchanges.

The goal is to make exchanging items **simple, transparent, and community-driven**.

---

## 🚀 Features

| Feature               | Description                                    |
| --------------------- | ---------------------------------------------- |
| 🔄 **Item Swapping**  | Propose exchanges instead of purchasing items  |
| 🔎 **Explore Items**  | Discover items available from other users      |
| 📦 **Item Listings**  | Add items you are willing to exchange          |
| 🤝 **Swap Offers**    | Send and manage swap proposals                 |
| 👤 **User Profiles**  | View information about other users             |
| 💬 **Chat**           | Communicate with users about potential swaps   |
| 🔐 **Authentication** | Secure user registration and login             |
| 📱 **Responsive UI**  | Designed to work across different screen sizes |

## 🔄 How It Works

```text
       ┌──────────────┐
       │   Add Item   │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Explore Items│
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Find a Match │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Propose Swap │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Chat & Agree │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │   JustSwap   │
       └──────────────┘
```

### 1. List

Add an item that you are willing to exchange.

### 2. Explore

Browse items listed by other users.

### 3. Match

Find something that interests you.

### 4. Propose

Send a swap offer for the item.

### 5. Connect

Chat with the other user and finalize the exchange.

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/GAYATHRI14-DO/JustSwap.git
```

Move into the project:

```bash
cd JustSwap
```

Install dependencies:

```bash
npm install
```

Create your environment file:

```bash
.env
```

Use `.env.example` as the reference for the required environment variables.

Start the development server:

```bash
npm run dev
```

The application will be available through the local URL shown in your terminal.

---

## 🔐 Environment Variables

Do **not** commit your `.env` file.

The repository includes `.env.example` to show the required configuration without exposing private credentials.
